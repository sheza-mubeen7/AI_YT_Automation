# 🎬 AI YouTube Automation System

An end-to-end AI-powered YouTube content automation workflow built with **n8n** that automates the process of transforming content ideas into structured, video-ready content.

## 🚀 Overview

Creating YouTube videos involves multiple repetitive steps: content planning, script generation, structuring, and preparing video data.

This workflow automates these processes using **n8n, Airtable, and Google Gemini 2.5 Flash**, reducing manual work and creating a repeatable content production pipeline.

## ⚙️ Workflow

Airtable
   ↓
Content / Topic Input
   ↓
n8n Automation
   ↓
Google Gemini 2.5 Flash
   ↓
Structured JSON Output
   ↓
JSON-to-Video Pipeline
   ↓
Video-Ready Content

## 🛠️ Tech Stack

- **n8n** — Workflow automation & orchestration
- **Google Gemini 2.5 Flash** — AI content generation
- **Airtable** — Content management & workflow database
- **JSON** — Structured data exchange
- **JSON-to-Video** — Automated video generation pipeline

## 🧩 Automation Flow

1. Add a video topic/content idea to Airtable.
2. n8n retrieves the content information.
3. Gemini 2.5 Flash processes the input.
4. AI-generated content is structured into JSON.
5. The structured output is passed to the video generation pipeline.
6. The workflow produces video-ready data for automated production.

## 💡 Why I Built This

The goal was to move YouTube content production from a manual, repetitive process toward an **AI-powered and repeatable automation system**.

Instead of manually handling every step, the workflow creates a structured pipeline where content can move from **idea → AI processing → structured output → video generation** automatically.
